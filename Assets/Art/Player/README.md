# Assets do Personagem

Coloque aqui os arquivos baixados dos packs de personagem. Sugestões que você
já escolheu:

- **Hero Knight** (Unity Asset Store) → pasta `HeroKnight/`
  https://assetstore.unity.com/packages/2d/characters/hero-knight-pixel-art-165188
- **Platformer Character Pack** (itch.io, merakintsugi) → pasta `PlatformerCharacterPack/`
  https://merakintsugi.itch.io/platformer-character-pack

⚠️ São assets pagos/com licença própria - baixe e importe você mesmo (eu não
tenho como comprar/baixar por você). Depois de importar, veja
`docs/GUIA_INTEGRACAO_ASSETS.md` na raiz do projeto para conectar as animações
ao PlayerController.
